Fix User Staff Status

Grant Django admin access to admin users

What does this fix?

This utility helps users who were created through the custom admin dashboard but cannot login to the Django admin panel at /admin/.

It will:

  • Find all users with "Admin User" status but without "Staff Status"
  • Grant them is_staff=True permission
  • Allow them to login to Django admin panel
