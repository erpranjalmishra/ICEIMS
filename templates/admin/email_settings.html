Setup Guide: Gmail SMTP Configuration
1
Enable 2-Step Verification (if not already enabled)

Gmail requires 2-Step Verification to create App Passwords

  1. Go to your Google Account: myaccount.google.com
  2. Navigate to Security section
  3. Under "Signing in to Google", enable 2-Step Verification
2
Generate App Password

Create a 16-character app password for your application

  1. Go to: myaccount.google.com/apppasswords
  2. Select Mail for the app type
  3. Select Other (Custom name) for device
  4. Enter "ICEIMS Conference" as the custom name
  5. Click Generate
  6. Copy the 16-character password (e.g., abcd efgh ijkl mnop)
3
Set Environment Variables (Windows PowerShell)

Configure your email credentials as environment variables

Option A: Temporary (Current Session Only)

$env:EMAIL_HOST_USER = "your-email@gmail.com" $env:EMAIL_HOST_PASSWORD = "your-16-char-app-password"

Option B: Permanent (Recommended)

[System.Environment]::SetEnvironmentVariable("EMAIL_HOST_USER", "your-email@gmail.com", "User") [System.Environment]::SetEnvironmentVariable("EMAIL_HOST_PASSWORD", "your-16-char-app-password", "User")
Replace your-email@gmail.com with your actual Gmail address and your-16-char-app-password with the password from Step 2
4
Restart Your Django Server

Environment variables only load when the server starts

# Stop the current server (Ctrl+C) # Then restart with: python manage.py runserver
5
Test Email Configuration

Verify your setup with the test command

python manage.py test_email --to your-test@email.com
If configured correctly, you should see "✓ Email sent successfully!" message
Troubleshooting Common Issues

Solutions:
  • Ensure you're using the 16-character App Password, not your regular Gmail password
  • Remove any spaces from the app password when setting the environment variable
  • Verify EMAIL_HOST_USER contains your full Gmail address
  • Make sure you restarted the Django server after setting environment variables

Solutions:
  • Enable 2-Step Verification in your Google Account
  • Generate a new App Password from Google Account settings
  • Check if the app password has expired (they don't usually expire but can be revoked)

Solutions:
  • Check your firewall settings (allow outbound connections on port 587)
  • Verify your internet connection is active
  • Try using port 465 with EMAIL_USE_SSL instead of EMAIL_USE_TLS
  • Check if your network blocks SMTP connections
